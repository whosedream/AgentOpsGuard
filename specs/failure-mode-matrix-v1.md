## 副作用重试规则

- 读取：在客户端约定次数内可重试。
- 写入、发送：只有上游支持同一个幂等键且能查询结果时才自动重试。
- 删除、付款、改权限：连接建立后发生超时一律视为结果未知，不自动重试。
- 内部回放、评测和注册表刷新：其数据库副作用和 Job 完成状态同事务提交，可在租约过期后重试。

故障测试必须分别在调用前、调用中、上游返回后但本地确认前注入中断，不能只测“服务一开始就
不可用”的简单情况。

## 已完成的真实进程演练

- Redis 容器在数据库提交后整体停止：发件箱保持待处理，同一地址恢复后真实 RQ Worker 完成。
- RQ Worker 在任务正文执行中被终止：租约过期后恢复，第二个 Worker 完成。
- 相同发件箱事件重复发送：固定 RQ 编号只保留一个队列项。
- 已批准 stdio 工具先产生副作用再丢失响应：硬超时后状态为 `outcome_unknown`，相同审批不再执行。
- 独立执行进程在领取提交后直接退出：PostgreSQL 保留 `execution_claimed`，租约到期转为
  `outcome_unknown`，替代进程不能再次领取；持有旧内存状态的进程也不能覆盖数据库中的新状态。
- Gateway 在上游返回后发现执行权已失效：丢弃上游返回内容，只向 Agent 返回固定错误，并记录不含
  返回正文、工具参数和凭据的 `execution.claim_lost` 审计事件。
- 结果未知的执行只有 `jobs:admin` 可核对；接口不接收原始证据、备注、URL 或工具参数，只保存外部
  证据的 SHA-256。确认成功/失败后关闭；确认未执行后恢复原请求，但仍重新检查到期时间、身份、
  工具版本、参数摘要和策略版本，并保持一次领取。
- 两个独立网关进程竞争真实 Redis 容量：同一上游只有一个进入，不同上游隔离，进程崩溃后租约自动释放。
- 两个真实 Gateway 通过 HTTP 同时调用真实 MCP 上游：占用期间第二个副本返回 429，释放后恢复。
- OpenBao Transit 使用不可导出 Ed25519 密钥签署审计链头：数据库历史和链头即使被重新计算为
  表面合法，旧封条仍能发现改写。
- 两个临时 PostgreSQL 16 实例完成自定义格式备份与空库恢复；迁移版本、审批执行封套、后台
  任务和审计链均复核通过。
