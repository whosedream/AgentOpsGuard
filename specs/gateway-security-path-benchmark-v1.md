# Gateway 安全路径基准 v1

本基准测量一次低风险工具调用经过身份校验、项目隔离、工具版本确认、参数扫描、策略快照、
策略落库和结果扫描的本地耗时。报告不保存请求正文或逐条结果。

运行：

```bash
uv run python scripts/benchmark_gateway_security_path.py --iterations 500
```

成功门槛沿用企业化路线图的初始建议：不含上游、OPA 和语义模型时，p95 小于 100ms、p99
小于 250ms，错误数为 0。

该结果只代表单进程 TestClient 与临时 SQLite 的组件基线，不能当作 PostgreSQL、多副本、真实
网络或峰值容量结论。生产发布前仍须在目标环境运行 2 倍峰值 30 分钟测试。

## 2026-09-04 本地结果

500 次已认证低风险调用错误数为 0；p50 14.490ms、p95 16.002ms、p99 17.121ms，平均
14.692ms，约 68.062 次/秒。本次关闭 OPA 和语义模型，上游为进程内固定响应，因此该结果只用于发现本项目自身
安全路径的性能回退。
