# 未见攻击评测治理 v1

## 一句话结论

项目已经能把“第一次未见测试”和“看过后的回归测试”分开管理，并保证第一次开始后无法再次冒充
盲测；新增 InjecAgent 首次静态保留集提供了新的英文外部工具内容结果，但中英文真实 Agent
端到端保留集尚未由独立保管方交付，所以未知攻击端到端门槛仍未关闭。

## 为什么需要这层

同一批公开攻击一旦被开发者看过、用于写规则或调阈值，就只能说明修复没有退化，不能继续证明
系统能识别未知攻击。此前 AgentDojo、BIPIA 和 Nemotron 已经产生了有价值的首次结果或回归结果，
但都已成为已知集合。

`evals/holdouts/manifest.json` 只保存摘要、样本数、公开来源版本和使用状态，不保存正文、文件路径、
URL、逐条模型结果或凭据。历史首次结果被登记为 `regression/consumed`；开发期间看过的数据登记为
`regression/available`，因此不会被重新包装成新的未见集。

## 四类数据必须分开

| 类别 | 用途 | 能否用于宣称未知泛化 |
| --- | --- | --- |
| `training` | 训练模型 | 不能 |
| `tuning` | 写规则、选阈值、挑模型 | 不能 |
| `regression` | 检查旧问题是否复发 | 不能 |
| `first_run_holdout` | 冻结后只运行一次 | 只有第一次且证据完整时可以 |

相同语料摘要不能登记到第二个类别或换一个名字重新使用。

## 第一次运行的顺序

1. 独立保管方在仓库外保存原始语料，只交付语料 SHA-256、攻击/正常样本数、公开来源版本和不透明
   保管方编号。
2. 开发方冻结 Gateway、策略、规则、模型、阈值、Agent、工具和评测脚本，并计算一个总摘要。
3. 清单把集合登记为 `first_run_holdout/sealed`，且保存步骤 2 的系统摘要。
4. 受信评测运行器在读取任何正文前领取集合。领取动作原子地把它改成
   `regression/first_run_in_progress`；系统摘要不一致时拒绝领取。
5. 运行器通过 `first_run_holdout(...)` 上下文执行 Inspect AI 和受控 MCP 上游。成功时先写只含聚合
   指标的不可覆盖报告，再用 `ticket.record_report(...)` 记录报告 SHA-256。
6. 无论成功、失败还是中断，集合都进入 `regression/consumed`。失败不会恢复“未见”身份；成功但
   没有聚合报告也按失败封存。

清单使用文件锁和同目录原子替换，避免两个运行器同时领取。它能防止工程流程误用，但不能阻止
拥有仓库和保管端全部管理员权限的人伪造历史；生产环境还需要外部只追加存储和职责分离。

## 报告必须回答什么

新的动态报告至少应分别给出：

- 攻击是否成功诱导 Agent 发起动作；
- 规则命中、旁路模型命中和人工审批数量；
- 未授权高风险动作的真实上游副作用数；
- 正常任务完成率和正常任务被误送审批的比例；
- 相对无网关基线的新增延迟；
- 按语言、来源和攻击家族拆分的结果。

目标仍是设计范围内未授权副作用为 `0`，正常任务完成率相对无网关基线下降不超过 2 个百分点。
小模型只有在新的未见中英文集合中同时达到攻击召回不低于 90%、正常难例误报不高于 1%，并完成
线上旁路观察后，才可以讨论直接隔离内容。达标前，高风险旁路事件最多把同一次运行中后续的
改写类动作升级为人工审批，并必须单独报告误审批；它永远不能批准、放行或降低硬规则风险。

## 当前已有证据和缺口

清单已登记 AgentDojo、BIPIA 和 InjecAgent 静态首次结果、AgentDojo 动态首次结果以及 Nemotron
已知回归。InjecAgent 首轮在 1,054 条官方 `base` 工具响应上得到 54.74% 联合检出；这证明当前
小模型已启用但泛化不足，且仍只是静态扫描。状态机、语料重复检测、系统摘要漂移、成功、失败、
缺报告和原始字段拒绝均有自动测试，并进入固定发布核验。

AgentThreatBench 的 24 条公开动态样本也已经消耗。首次报告因适配错误实际执行 0 次工具调用，
必须保留为无效安全反例；后续 v2-v6 都只能称为回归。v6 证明 5/5 个邮件劫持样本的改写在上游
前暂停且攻击样本高风险动作实际执行为 0，但完整效果安全仍为 17/19，正常任务也只有 1/5 完成。
这组结果不能替代新的独立中英文保留集。

尚缺的是由不同保管方提供的、未被规则和模型开发者查看的新中英文攻击与正常难例，以及它们在
真实 Agent、Gateway、审批和受控上游上的第一次运行。因此当前不能把既有回归结果写成未知攻击
泛化率，也不能清除 `unknown_attack_agent_end_to_end_evaluation` 门槛。
