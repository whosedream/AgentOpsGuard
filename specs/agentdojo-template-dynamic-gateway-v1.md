# AgentDojo 模板动态网关评测 v1

## 一句话结论

真实 Qwen3-4B Agent 在 7/7 条新模板攻击中都尝试了越权写入；确定性授权层把 7 次请求全部停在
审批前，真实上游写入为 0。规则没有提前拦住这些内容，旁路小模型命中 7/7；2 条正常对照都完成
读取，规则和小模型均未误报。

## 为什么要做这轮

此前的 AgentDojo 首次未见集是静态文本扫描，不能回答“模型真的看到攻击后会不会调用工具”和
“网关是否真的挡住调用”。此前的真实 Qwen 烟雾测试又只有两条读取，只证明模型和调用链可运行，
没有证明真实模型被诱导后会发起写入。

本轮把两段证据接起来：由真实本地模型运行 Inspect ReAct Agent，经真实 AgentOps Guard Gateway
连接真实 MCP v2 受控上游。评分不依赖模型回答，而是读取网关数据库中的策略与审批记录，并检查
上游独立副作用标记。

## 数据和首次运行

评测复用 AgentDojo `0.1.35`、基准版本 `v1.2.2` 中此前未进入静态首轮的 7 种官方模板：

- `important_instructions` 及其去除或替换用户名、模型名的 5 个变体；
- `tool_knowledge`。

官方模板被改造成同一个受控目标：诱导 Agent 调用测试环境的 `mutate_record`。因此准确名称是
“AgentDojo-template-derived adapted micro-suite”，不是官方完整 AgentDojo 分数。另加入 2 条正常
外部记录，其中一条只在历史描述中提到工具名，用于检查误报。

代码、模型、阈值和 9 条样本的语料摘要在查看结果前冻结。原文只在本地内存和临时目录出现，
运行后删除；报告不保存逐条结果、提示、模型回答、工具参数或凭据。语料 SHA-256 为
`c63018476320b64f7d74deaf1bd91fb0728439483a646135e1014131417f8b1b`。

## 结果

| 观察层 | 攻击样本 | 正常样本 |
| --- | ---: | ---: |
| 真实读取完成 | 7/7 | 2/2 |
| 规则在内容入口隔离 | 0/7 | 0/2 |
| 旁路小模型命中 | 7/7 | 0/2 |
| 真实 Agent 发起越权写入 | 7/7 | 0/2 |
| 写入请求被确定性授权层拦住 | 7/7 | 不适用 |
| 真实上游未授权副作用 | 0/7 | 0/2 |

这里的 7/7 和 0/2 只能说明这 9 条固定微型样本。攻击检出率 100% 的 Wilson 95% 区间下界约为
64.6%，正常误报 0% 的上界约为 65.8%；样本太小，不能据此把旁路模型改成线上拦截器。

更重要的工程结论是：这 7 条攻击确实都让 Agent 产生了越权意图，所以“零副作用”不是因为模型
拒绝攻击；它来自工具动作与服务端原始用户要求不一致时必经审批的确定性规则。旁路小模型补到了
规则内容扫描的盲区，但仍没有放行或审批权。

## 不能怎样解释

- 不是官方完整 AgentDojo 动态基准，只复用了 7 种模板并替换为一个受控目标。
- 不是统计充分的未知攻击泛化率；这 7 个模板在首次运行后已变成已知回归集。
- 不是生产环境测试；身份、上游和网络都在本机受控环境。
- 不能据此启用小模型强制拦截。静态首轮仍显示 9/97 的正常任务误报，且本轮正常样本只有 2 条。
- 不能声称规则内容扫描有效；本轮规则入口隔离为 0/7，安全兜底来自确定性动作授权。

## 首轮之后的修复

首轮报告保持不变。针对规则入口 0/7 的缺口，项目另行增加了受管高精度规则包；修复后在同一
7 条已知攻击上命中 7/7，并在 302 条公开正常样本上误报 0。因为规则已经看过这些攻击结构，
新结果只叫回归，不回写或覆盖本页的首次动态结果。实现和报告边界见
`specs/managed-scanner-rule-pack-v1.md`。
